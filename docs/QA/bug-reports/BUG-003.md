
## BUG: 
Face turn inputs not consistently triggering in-game actions

## Description:
The face turns in-software are registering flawlessly and providing inputs consistently. when tested in notepad, every keypress executes as intended. But when Dark Souls 3 is booted up and inputs from cube + software are provided to the game, the actions in-game are sporadic and don't function consistently. an R turn is made and light atk triggers, but when repeated, does not trigger light atk. combinations of actions do not queue up and execute properly. Also, there is a noticeable and consistent delay between face turn and in-game execution of actions.

## Steps to reproduce:
1. connect cube to software using standard orientation
2. boot up Dark Souls 3.
3. get into gameplay scene and attempt to use cube to execute in-game actions such as attacks, dodge rolls, and item use.

## Expected behavior:
all inputs from cube register and execute intended in-game action comsistently and with little input delay.

## Actual behavior:
inconsistency in-game executing intended actions with input from the cube. inputs frequently ghosting and consistently execute with significant delay.
