
## BUG: Inconsistent BLE connection on startup

## Description:
when software is starting, initial detection of cube is failing something around 1/5 of attempts. If initial detection succeeds, the 3 connection attempts are successful a vast majority of the time, but also occasionally fail. Root cause still unknown.

## Steps to reproduce:
1. ensure cube is charged and paired to PC.
2. ensure MAC address for cube is entered properly in software.
3. start software, wait for detect/connect attempt.
4. if successful, stop software and repeat step 3 until a failure occurs.

## Expected behavior:
Cube successfully connects on every attempt when software is booted up.

## Actual behavior:
Seemingly random failures to detect and connect occur on startup. Not often enough to consider software unusable or QA fail. Still needs worked out.
