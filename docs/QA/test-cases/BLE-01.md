## ID: BLE-01

## Title: Cold start connection

## Preconditions:
- Gocube Edge has had NO face turns made on it for 10 minutes before starting test. cube must be in sleep state.

## Steps:
1. Leave sleep state Gocube sitting on desk and DO NOT make any face turns on it.
2. Run software for startup detection/connection sequence to attempt to connect to cube.
3. Observe and note success or failure of detection AND connection attempts, and which step failed if applicable.

## Expected Result:
Cube successfully is detected and connects to software from sleep mode.
