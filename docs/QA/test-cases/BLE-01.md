## ID: BLE-01

## Title: Cold start connection

## Preconditions:
- Gocube Edge in sleep state (only requires not being connected via bluetooth to a device for 1-2 seconds)

## Steps:
1. Place Gocube on desk or hold it steady in neutral position (Green facing you, White on top)
2. Run software for startup detection/connection sequence to attempt to connect to cube.
3. Observe and note success or failure of detection AND connection attempts, and which step failed if applicable.
4. Repeat steps 1-3 10+ times.

## Expected Result:
Cube successfully is detected and connects to software from sleep state.
